# 第二阶段来源隔离补充核查

在读取最终预测之前，进一步检查了完整请求以外的来源关系。初版 `experiment-v3` 按翻译题、段落、问题 ID 隔离，但检索题的问题 ID 不等于独立文档；PAWS 的完整句对也不等于独立原句。

旧切片中，训练与最终检索题共享 18 篇正确文档，若包括负候选则共享 49 篇。另有 3 个规范化句子跨校准或开发与测试出现。即便问题不同，也不足以声称来源独立。两次损失函数对照的训练保持原样，按结构来源重新整理评测，不根据测试表现删除题目。此时最终集及 Jev 的新题预测都尚未运行。

`source_isolation.py` 使用 PAWS 原始英文句子连接翻译和不同句对，用英文前提连接 XNLI 同源题，用所有候选文档连接检索题。共享来源的连通分量用于统计分组。去重依据实际材料关系，不是标签或模型回答。

新登记目录为 `data/phase2/strict-v1`：

| 角色 | 题目数 | 来源连通组数 |
|---|---:|---:|
| 来源审计记录（含重复） | 8,712 条 / 5,800 种请求 | 2,830 |
| 开发 | 707 | 305 |
| 校准 | 649 | 272 |
| 封存测试 | 1,171 | 503 |

开发集剔除 19 道来源已在训练中出现的检索题，校准集剔除 26 道。封存集剔除 4 道存在原句重叠的释义题；检索的 80 题按预先固定种子重新抽样，正确和负候选文档均未在训练、原开发或原校准材料中出现。仍然使用官方 test 查询、相同的长度限制、随机候选数量和未判断负例口径，不把它称为完整检索评测。

对未更改请求和标签的开发题，复用既有预测并重新汇总，保留原始报告。任务宏平均准确率：round4 为 74.37%，第一轮 answer-ce 为 85.15%。推断 85% → 81% 的回归仍然存在，来源清理没有解决这项问题。

来源审计记录数不等于累计训练呈现次数：相同 expanded 数据曾用于 round3 和 round4。训练量需沿最终 adapter 的父权重链单独汇总。

额外配对扰动以 `data/phase2/robustness-v5` 为准，共 140 题，来源于最终题；这些是稳健性检查，不增加独立样本数。在读取预测前，v5 将 v4 的通用元问题否定改为按任务直接否定条件，避免把相反回答指令拼在一起。旧快照保留。改进训练集登记为 `data/phase2/refinement-v2`，2,800 条，包含多字段数值规则反事实对、原任务回放和未在第二阶段使用的自然训练样例；是否实际使用以训练记录为准。

性能门槛和收益递减停止条件仍按 [验收协议](phase2-acceptance.md)，没有因来源清理而放宽。原始快照保留供审计，后续模型选择、校准和最终比较以严格来源版本为准。公开语料的未知预训练污染、未检测出的语义近重复仍是限制。
