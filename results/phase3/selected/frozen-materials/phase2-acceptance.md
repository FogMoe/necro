# 第二阶段验收与停止条件

本协议在第二阶段训练和封存测试预测之前记录。基模固定为 Qwen3.5-0.8B，参考服务固定为 Jev 1.13.0。轻量方案按下述性能门槛或收益递减条件结束。

## 数据与比较

- `data/phase2/experiment-v3` 为登记的数据快照。八类任务开发集有 726 条，训练集 2,582 条，校准集 477 条。当前封存集 775 条包含六种新任务；推断和意图另取未使用的官方测试记录，在任何最终预测前补充登记。
- 原有测试只用于历史回归。按来源、段落、双语翻译和反事实组隔离；报告各组的实际数量。测试不能用于选择起点、损失、温度或训练数据。
- 分开报告自然人工标注、派生候选答案、精确规则 oracle 和存在未判断负例的候选检索。候选抽取和文段选择均按给定候选集计算。
- 中英文覆盖按任务分别说明。BoolQ 和 SciFact 使用英文来源。

## 开发阶段

1. 共同比较起点选 round4：新开发集八任务宏平均 74.55%，round3 为 74.29%；此前同口径校准也支持 round4。该选择仅依据开发数据。
2. 首批两个实验均从 round4 出发：rank 16、学习率 3e-5、seed 2026、batch 4、累积 2、同一训练集、一轮。仅比较 answer-ce 与 candidate-ce。后者在多 token 标签上保留全词表答案损失。
3. 比较任务宏平均、各任务、分语言、Score 归一化 MAE。候选通常需宏平均提高至少 2 个百分点，原有推断/意图任一任务下降不得超过 3 个百分点；明显的关键能力改善可以单独分析，但不得掩盖回归。
4. 对有收益的设置换一个种子复验。校准使用同一独立切片与同一方法；选择冻结后才测最终数据及 Jev。
5. 后续实验必须针对明确开发集证据，一次调整一项主要因素。连续两个有针对性的方案均不足 1 个百分点，且未修复关键任务短板时，记录收益递减，结束轻量探索。

## 性能通过条件

同题最终测试须同时满足：八任务宏平均准确率与 Jev 差距不超过 3 个百分点；每个核心任务差距不超过 5 个百分点；Score 按等级跨度归一化 MAE 不高于 Jev 加 0.05；任务宏平均 Brier 不高于 Jev 加 0.03。报告分语言结果、来源组配对 bootstrap 区间及概率精度差异。

另需选项顺序、否定、缺失输入等鲁棒性记录，协议测试、保存重载验证、延迟/显存测量。远程延迟包含网络耗时。
